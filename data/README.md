# Data Workflow

This project keeps original data separate from generated data.

## `data/raw/`

Store the original downloaded dataset here. Files in this directory should remain unchanged so experiments can always be traced back to the source data.

## `data/processed/`

Store cleaned, transformed, and feature-engineered datasets generated by the preprocessing pipeline here.

## `data/external/`

Store any third-party reference files here if they are needed later.

Never modify the original raw dataset directly. Create processed copies through reproducible scripts or notebooks.
